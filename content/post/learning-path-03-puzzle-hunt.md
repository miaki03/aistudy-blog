## 03 · Puzzle Hunt 结构学：题型、提取与实战

> 覆盖 W7–W9（主攻）+ W14（档案）+ W15（出题）。Puzzle Hunt 与 CTF 最大的区别：**没有 hint 系统、没有 flag 格式、核心技能是「提取」（extraction）**。理解了提取，你就理解了这个领域 80% 的题。

---

## 1. 本模块目标

- [ ] 能看懂一道题的结构：题面 / 数据 / 主题 / 提取 / 答案 各在哪
- [ ] 能从「不自然的地方」判断该用哪种提取
- [ ] 能单人完成一个完整的小型 hunt（3–4 小时）
- [ ] 能识别 meta 谜题的运作方式
- [ ] 能改写一道题（出题的第一小步）

---

## 2. Puzzle Hunt 是什么（和 CTF 的差异）

| 维度 | CTF | Puzzle Hunt |
| --- | --- | --- |
| 答案格式 | `flag{...}` | 一个单词/短语（常全大写、只含字母） |
| 提示 | 有 hint 系统 | 通常没有，靠推理与守恒 |
| 核心技能 | 工具 + 漏洞 + 脚本 | **提取 + 枚举 + 常识** |
| 结构 | 单题独立 | 常有 meta：多题答案喂给一道总谜题 |
| 时间 | 限时比赛 | 可无限期做档案题 |
| 单人 | 部分可玩 | 完全可玩（只是慢） |

**一句话本质**：题目给你一堆数据，数据里藏着规律；用规律**提取**出一个答案。难的从来不是数据本身，而是「该用哪种规律」。

---

## 3. 一道题的结构解剖

```
题面（flavor text）  ← 往往藏双关、暗示主题与提取方式
   │
   ├── 数据：一组词 / 网格 / 图片 / 列表 / 文章 / 地图 / 音频
   │
   ├── 主题：所有数据围绕同一个概念（颜色、字母序、地理、音乐…）
   │
   ├── 提取：利用主题规律，从数据中取出字母
   │
   └── 答案：一个词，喂给 meta 或直接提交
```

**读题时按这个顺序问自己**

1. 数据是什么形态？（词表 / 网格 / 图片 / 段落）
2. 有多少项？这个数量有没有意义？（8 项 → 8 个字母？）
3. 答案多长？很多题面会写 `(5)` 或 `(4,3)` 表示答案长度。
4. 标题在暗示什么？（标题几乎从不白给）
5. 数据里有没有「明显不自然」的地方？（多余空格、颜色、粗体、异常项、重复项）

---

## 4. 题型的五大类

### 4.1 词谜 / wordplay

- 变位词（anagram）、rebus、同义替换、隐藏词（藏头/藏尾/隔字）
- 英文谜题重镇，也是英文弱的人最大的坎
- **对策**：优先做「不靠 wordplay」的题型（网格/图片/编码）；wordplay 类借助工具：OneLook（词典反查）、Nutrimatic（正则搜词）、变位词求解器

### 4.2 网格题（grid）

- 填字、数独类、kakuro、像素画、网格里藏字
- 提取方式：对角线、蛇形、螺旋、读方向、按颜色分组、按大小排序

### 4.3 枚举题（enumeration / list）

- 给你一串条目（国家、年份、电影、元素），要求按某个顺序排列后取字母
- 提取方式：排序（字母序/数值/时间/长度）、配对、交叉

### 4.4 图片题

- 看图找不同、数数、颜色、位置、隐藏文字
- 提取方式：颜色→字母、数量→数字→字母、位置坐标、图片拼接

### 4.5 Meta（元谜题）

- 前面若干题的答案按顺序喂进一道总题
- 常见结构：答案长度、首字母、按答案排序、用答案当索引
- 单人做档案时，meta 是「检验你是否真的解对了」的天然校验器

## 5. 提取方法清单（遇到卡住就逐条试）

| # | 提取法 | 触发信号（什么时候想到它） |
| --- | --- | --- |
| 1 | 取第 n 个字母 | 数据里出现数字，且数字 ≤ 对应词的字母数 |
| 2 | 首字母 / 尾字母 | 条目很多、每个条目都短 |
| 3 | A1Z26 | 出现 1–26 范围的数字 |
| 4 | 二进制 / 摩斯 | 只有两种状态（黑白、长短、开合、有无） |
| 5 | 排序后取 | 数据本身有可排序属性（年份、大小、字母序） |
| 6 | 颜色 / 视觉属性 | 图片题、彩色文字题 |
| 7 | 网格路径 | 有规则网格、有起始点或方向提示 |
| 8 | 配对 / 找差异 | 数据成对出现、两两相似 |
| 9 | 藏头（acrostic） | 每行/每句/每项开头能组成单词 |
| 10 | 索引表（元素/扑克/星座/星期） | 主题明显指向某个封闭集合 |
| 11 | 重复项取一次 | 数据里有异常重复 |
| 12 | 反向 / 镜像 | 数据看起来「倒过来才对」 |

**核心纪律**：**先穷举触发信号，再动手**。写一张纸：列 5 个可能的提取方向，每个方向花 5 分钟试，不行就划掉。这比死盯一个方向 40 分钟高效得多。

## 6. 解题循环（标准流程）

```
① 读题面 + 标题（3 分钟）
② 数数据、看答案长度、找不自然处（5 分钟）
③ 列 3–5 个提取假设 → 每个试 5 分钟
④ 出现「半可读」结果 → 说明方向对了，继续
⑤ 得到完整答案 → 校验：它像不像一个词？长度对得上吗？
⑥ 写复盘：我靠哪个触发信号想到的？
```

**低温模式**（🧊，卡住时用）：只读题面，不许查任何东西，先写下 3 个猜想再动手。这能防止「一上来就乱试工具」。

## 7. 单人怎么练

### 7.1 资源定位

| 资源 | 适合 | 特点 |
| --- | --- | --- |
| Puzzled Pint 档案 | 入门 | 每月一组，难度友好，有答案 |
| MIT Mystery Hunt 档案 | 进阶 | 题量大、质量高，但很多题需要英语文化背景 |
| Galactic Puzzle Hunt 档案 | 进阶 | 现代风格，结构清晰 |
| Puzzle Hunt Calendar | 找活动 | 看当年有哪些 hunt 可参加 |
| Puzzling Stack Exchange | 卡住时 | 问「这类题的切入方式」 |
| NPL（National Puzzlers' League） | 词谜专门练 | 纯 wordplay，英文门槛最高 |

> 具体链接与可用性见 [05 工具与资源](/p/learning-path-05-resources/)。**中文系统性 Puzzle Hunt 教程目前稀缺**，已在 [总览的「资料补给机制」](/p/learning-path/)里挂了一条。

### 7.2 单人练习规则

- **先限时，再对答案**：一道题最多 40 分钟，到点记下卡点，看答案，然后**必须复盘「我漏了哪个触发信号」**。
- **做完一个 hunt 再开下一个**：半途而废的 hunt 没有训练价值。
- **专题突破**：如果发现自己总在 wordplay 上卡住，就专门挑 10 道 wordplay 小题集中练，而不是逃避。
- **允许用答案**：答案不是作弊，是学习材料——前提是你看完能复述提取逻辑。

## 8. 周任务（W7–W9）

### W7 · 结构学

- 学：§3、§4、§5
- 练：5–8 道入门题（Puzzled Pint 优先）
- 交：题型分类笔记（每道题标：题型 / 数据形态 / 提取法 / 卡点）
- 验收：拿到一道新题，能在 3 分钟内说出「这题大概想让我做什么」

### W8 · 提取与 meta

- 学：meta 结构（§4.5）、提取清单（§5）
- 练：推进一个小型 hunt 的前半（≥ 5 题）
- 交：半程记录 + 卡点复盘
- 验收：能解释「为什么这几题的答案能拼成 meta 的输入」

### W9 · 完整 hunt + 出题初体验

- 练：独立完成一个小型 hunt（3–4 小时，允许少量超时）
- 练：**改一道题**——把原题的提取法换一种
- 交：完整 hunt 复盘 + 1 道改写题（含答案）
- 验收：改写题能被别人（或隔天的自己）在 20 分钟内解出

## 9. 出题入门（W9 与 W15 用）

出题是最快的「反向理解」。从这三步开始：

1. **改一道现成题**：保留数据，换提取方式（例如原来取首字母，改成按长度排序后取）。
2. **换一层外衣**：保留提取，换主题与数据（把「颜色」换成「乐器」）。
3. **自测**：隔一天自己做一遍，若自己都想不起怎么解，说明题太绕。

**好题的三个标准**（单人自测用）

- [ ] 有唯一合理的「第一反应」（不要求解题者瞎猜）
- [ ] 卡点来自「没想到」，而不是「看不到」
- [ ] 答案长度与题面提示一致

---

## 10. 验收标准

**W9 结束时**
- [ ] 完整做完 1 个小型 hunt（≥ 6 题）
- [ ] 题型分类笔记 ≥ 15 道
- [ ] 能口头解释 meta 的原理
- [ ] 出过 1 道可解的改写题

**W14 结束时**
- [ ] 限时 6 小时完成一个中等档案（≥ 10 题）
- [ ] 复盘里能列出「我这次用了 5 种提取法，其中 3 种是第一次用」

---

## 11. 常见卡点

| 卡点 | 真相 | 处理 |
| --- | --- | --- |
| 完全没头绪 | 很正常，先看标题 | 标题 + 答案长度 + 不自然处，三件事能救 70% 的题 |
| 想太多 | 入门题往往很简单 | 先试最笨的提取（首字母） |
| 卡在一个方向出不来 | 沉没成本 | 40 分钟强制换方向，列出 5 个假设 |
| 英文 wordplay 不会 | 最大的客观门槛 | 用 OneLook / Nutrimatic；优先做非 wordplay 题 |
| 做不完一个 hunt | 太贪 | 一个 hunt 只做前半也算完成，但要复盘 |
| 看了答案还是不懂 | 说明提取逻辑没看懂 | 把答案反推回去：答案的每个字母来自哪？ |

---

## 12. 一句话自检

> 「给我一道题，我能说清它想让我从哪、用什么规律、取出什么。」

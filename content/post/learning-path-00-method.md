## 00 · 学习方法、卡关策略与复盘

> 这份文件解决三件事：卡住时怎么办、每次做完留下什么、英文资料怎么吃下去。
> 主线的难度不在知识，而在「一个人卡住时没有队友把你拽回来」。这里就是那个替补。

---

## 1. 三级卡关升级策略（全教材最重要的一节）

**规则先行：单题投入 90 分钟必须升级，不许硬耗。** 硬耗的唯一产出是挫败感，而不是技能。

### L0 — 自查（先花 5 分钟问自己 5 个问题）

1. 题目类型我判断对了吗？（编码变换 / 文件隐写 / 流量取证 / 纯逻辑 / 古典密码）
2. 最笨的检查做了没有？`file`、`xxd | head`、`strings`、`grep -a flag`。
3. 输入数据对吗？文件是否完整下载、是否真的解压了、编码是否搞错（UTF-8/GBK）。
4. 我能不能用一句话写出「题目要什么、我缺什么」？写不出来 = 还没理解题。
5. 我是不是在重复同一个动作第三遍？（是 → 换方向，别再用同一个工具）

### L1 — 官方提示

大多数平台有 hint 系统（picoCTF 类平台常要少量积分或解锁）。**该用就用**，提示的代价远低于硬耗 3 小时。题目描述里的双关、评论区别人的提问，也都是线索。

### L2 — 看 writeup，但有纪律

看 writeup 的正确顺序（防止「一看就懂，一关就废」）：

1. **只读标题和前 3 行**。如果这 3 行已经让你知道下一步 → 立刻关掉，自己试。
2. 还不够 → **只看它用了什么工具 / 第一步做什么**，然后关掉自己试。
3. 仍然不行 → 看完整解法，但**必须关掉重做一遍**，并在错题本写一行「我为什么会卡在这里」。

> 判据：看 writeup 后不能自己复现 = 这题没学会，只是看懂了。

### L3 — 超纲归档（最容易被忽略，却最重要）

满足以下任一条件，**记录并跳过**：

- 落在 [总览的「不覆盖清单」](/p/learning-path/)里（pwn、高级 web、密码学深水区、大型逆向…）。
- L2 之后仍然完全无法复现。
- 已经投入超过 3 小时且没有可描述的进展。

归档动作只要 20 秒：在错题本写「超纲：xxx，原因：需要 yy 前置知识，回补时机：zz」。**跳过不是失败，是排期。**

## 2. Writeup 两档制（别把时间全花在写作上）

### 速记档（平时用，5–10 分钟）

```markdown
## 题目名 | 平台/分类/难度/耗时
- 现象：一句话说清题目给的是什么
- 卡点：一句话说清我卡在哪
- 解法：3 步以内
- 关键命令/代码：1–3 行
- 下次记住：一句话
```

### 完整复盘档（每周交付物、比赛后用，20–40 分钟）

```markdown
## 题目名

### 1. 题目给了什么
（输入数据、题面暗示、答案格式）

### 2. 我的第一反应，以及它为什么错
（这一节最有价值：记录错误路径，而不是只记正确路径）

### 3. 正确路径图
（3–6 步，每步一句话：看到 X → 用 Y → 得到 Z）

### 4. 关键卡点与突破方式
（我用了 L0/L1/L2 哪一级才突破？）

### 5. 可复用知识
（进错题本 / 术语表的条目，各 1 条）

### 6. 如果重来，我怎么更快
（1–2 条具体动作，不要写「多练习」这种废话）
```

**时间预算**：平时速记；每周只有 1 次完整复盘。不要每道题都写完整复盘——那是写作课，不是解谜课。

## 3. 笔记结构（每周一个文件，够用就停）

`~/ctf/notes/wN.md` 用这个骨架，不要发明复杂系统：

```markdown
# W3 笔记

## 本周学了什么（3 条，每条一行）
## 本周工具新技能（命令 + 作用，最多 3 条）
## 本周卡点（原样记录，别美化）
## 本周 1 个「原来如此」时刻
## 下周要回查的一条
```

**不做的**：不建 Obsidian 插件体系、不做双链、不做标签分类、不做知识图谱。**一个目录 + 一个固定骨架**就是上限。

## 4. 错题本 + 每周 20 分钟回看

### 错题本格式（`~/ctf/mistakes.md`，全局一个文件）

| 日期 | 题目 | 症状（我看到什么） | 真因（我漏了什么） | 下次的检查动作 |
| --- | --- | --- | --- | --- |
| W3 | xxx | 文件打不开 | 没先跑 `file` 看真实类型 | 拿到文件先 `file` + `xxd \| head` |

**只记一行，不写小作文。** 「下次的检查动作」必须是可执行的一句话，否则这条不算记完。

### 每周 20 分钟回看流程（固定在复盘时段里做）

1. 读本周新增的错题条目（通常 3–8 条），只读，不整理。
2. 从上周做过的题里挑 **1 道**，不看答案重做一遍。
3. 如果重做失败 → 把这条挪进「本周卡点」，下周优先处理。
4. 其余时间不延长。20 分钟到就停。

> 为什么只重做 1 道：复习的价值来自「提取练习」而不是「重读」。1 道认真重做 > 10 道翻答案。

## 5. 英文资料消化工作流（科学但轻量）

### 第 0 步：先登记成「资源卡」，再决定读不读

```markdown
### 资源名
- 链接：
- 是什么：一句话
- 难度：★1–★5 ｜ 预计：xx 分钟
- 读完要做到：一个可检验的动作（例如「能解释 LSB 隐写怎么提取」）
```

**先写卡再读**，能砍掉一半「点开就关」的链接。

### 第 1 步：看结构，不逐字读（5 分钟）

只看标题、小标题、代码块、结论段。判断：这篇值不值得精读，还是只需要抄一个命令。

### 第 2 步：翻译工具逐段对照

- 浏览器插件「沉浸式翻译」或 Edge 自带「翻译此页」。
- 原则：**英文原文在左，中文在右，逐段看**。不要整篇一键翻译后只看中文——那样术语全丢。
- 命令、代码、工具名一律按原文照做，不要看中文翻译版本。

### 第 3 步：术语查表

[05 工具与资源](/p/learning-path-05-resources/) 里有中英日术语表。表里没有的词，自己加一行（这本身就是记忆动作）。

### 第 4 步：写 5 行中文摘要（收尾，必做）

```
1. 这篇在讲什么
2. 关键机制（一句话）
3. 我学到的一个具体动作
4. 我还有一个疑问
5. 下一步（做哪道题验证）
```

### 明确不做的四件事（防止把学习变成工程）

1. ❌ 不整篇预翻译、不攒 PDF 转中文的库。
2. ❌ 不写爬虫/自动翻译脚本。
3. ❌ 不追求读懂每个词——**读懂「这一步该敲什么命令」就够了**。
4. ❌ 不因为英文弱就绕开英文资源；绕开等于放弃最好的那批材料。

> 你提供 PDF 或链接时，我负责把这套卡片直接写好，你只管读。分工就到这里。

## 6. 单人 ≠ 孤岛：求助渠道与提问模板

### 可用的求助渠道（按优先级）

| 渠道 | 适合问什么 | 备注 |
| --- | --- | --- |
| 平台官方 Discord/论坛 | 平台题目卡住、环境报错 | picoCTF/CyLab、HTB、THM 都有 |
| CTFtime 的 writeup 聚合 | 某场比赛某题怎么做 | 搜「赛事名 + 题目名」 |
| GitHub 搜索 | `题目名 writeup`、工具用法 | 大量真实 writeup 仓库 |
| r/securityCTF、r/puzzles | 方法论、思路卡点 | 英文，但回复快 |
| Puzzling Stack Exchange | 谜题本身的设计与解法讨论 | 问「这类题一般怎么切入」很好用 |
| 中文：先知社区、看雪、CTF Wiki | 中文系统教程、WriteUp | 术语可能与英文不同，注意对照 |

### 提问模板（照抄，回复率翻倍）

```
【我卡在】题目名 + 链接 + 分类/难度
【我试过】1. … 2. … 3. …（按顺序，含完整命令）
【我看到的】完整报错或输出（贴文本，不要截图）
【我的判断】我认为下一步该 ……，但 …… 不通
【我需要的】提示方向即可，不要直接给答案
```

### 问 AI 的正确姿势（你已经在用，这里写清纪律）

- **给完整数据**：贴 hex、贴报错、贴文件头，而不是「这个题怎么解」。
- **让它当教练**：先问「我下一步该检查什么」，而不是「答案是什么」。
- **它给的命令自己跑**：AI 会编造不存在的工具参数。
- **别让它替你写整份 writeup**：写复盘那一步是学习本身，代写等于放弃。

## 7. 时间盒与心态设计

| 场景 | 规则 |
| --- | --- |
| 单题 | 90 分钟上限，到点按 L1/L2/L3 升级 |
| 单日 | 40–90 分钟也有效，碎片时间只做「读题面 + 写 3 个猜想」 |
| 单周 | 5–10 小时封顶，超时不加练（防倦怠） |
| 连续两天没进展 | 换模块，不换目标（去做另一条线的保温题） |

**三条心态规则**

1. **记录「卡点」，不记录「卡住」**——前者是信息，后者是情绪。
2. **允许跳过，且跳过要留记录**——排期，不是放弃。
3. **收集工具是逃避**——每周最多 3 个新工具，用完才加。

## 8. 每周复盘清单（贴在 `06` 的打卡表旁边）

- [ ] 本周交付物完成（速记或完整复盘）
- [ ] 错题本新增 ≥ 1 条，且每条都有「下次的检查动作」
- [ ] 20 分钟回看做了：重做上周 1 题
- [ ] 本周新工具 ≤ 3 个，且每个都实际用过
- [ ] 记录 1 条「下周要回查」
- [ ] 判断本周是否 ★ / ☆，以及是否需要启动停摆周

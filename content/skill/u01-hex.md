## 读完能做什么

给定 0 到 255 的十进制数，你能手写出它的两位十六进制写法，并说明一个字节为什么正好两位。

## 前置

命令都在 Ubuntu 终端里输入（开始菜单搜 `Ubuntu`，搜不到就回 第 1 章）——PowerShell 里没有 `xxd`。本章不需要先站到某个文件夹；1.3 的文件会先复制到你当前文件夹。

本章用到的四个词：

- **字节（byte）**：8 个二进制位，能表示 0 到 255 这 256 个数（第 1 章 给过）。
- **二进制位（bit）**：只有 0、1 两种取值的最小单位；怎么写属 第 8 章，本章只在旁注里用它。
- **十六进制（hex）**：用 16 个符号 `0`–`9`、`a`–`f` 计数，逢 16 进一。本章说「一位」「两位」，指的是十六进制字符，不是二进制位。
- **提示符 `$`**：行首的 `$` 表示「这行是命令」，不是你输入的内容；命令块第一行的 `$` 不要输入。

命令名打错时（软件版本号可能与你的不同）：

```console
$ prinf '%x\n' 15
Command 'prinf' not found, did you mean:
  command 'printf' from deb coreutils (9.4-3ubuntu6.2)
  command 'print' from deb mailcap (3.70+nmu1ubuntu1)
Try: sudo apt install <deb name>
```

第一行说找不到 `prinf`；后面的行是它猜你想打 `printf` 和装软件的建议，本章忽略。路径错是另一种报错，1.3 会见到。

## 1.1 一位十六进制装得下四位二进制

```console
$ printf '%x\n' 15
f

$ printf '%x\n' 16
10
```

`printf` 的第一个参数 `'%x\n'` 叫格式串，就是告诉 `printf` 怎么排版的模板：`%x` 是「写成十六进制」，`\n` 是换行。单引号让 shell 不要先处理它；`\n` 由 `printf` 自己解释成换行。

- 15 打成 `f`：`0`–`9` 共 10 个符号，`a`–`f` 共 6 个，10 + 6 = 16 个符号；第 1 个符号 `0` 代表 0，所以第 16 个符号 `f` 代表 15。
- 16 打成 `10`：符号用完了，16 只能记成「1 个 16 加 0 个 1」，这是逢 16 进一。

每一位的值：从右往左，每位是它右边相邻那一位的 16 倍；最右一位是 1，往左一位是 16。所以 `10` = 1×16 + 0 = 16。写两位时，左边那个字符乘 16，右边那个字符乘 1。

> **约定** 一位十六进制正好对 4 个二进制位，这条要用二进制位的知识（第 8 章 讲）；本章说明「为什么两位」不靠它，靠 1.2 的乘法。

**速查：0–15 与 0–f**

| 十进制 | 十六进制 | 十进制 | 十六进制 |
| --- | --- | --- | --- |
| 0 | 0 | 8 | 8 |
| 1 | 1 | 9 | 9 |
| 2 | 2 | 10 | a |
| 3 | 3 | 11 | b |
| 4 | 4 | 12 | c |
| 5 | 5 | 13 | d |
| 6 | 6 | 14 | e |
| 7 | 7 | 15 | f |

**U01.1-01** 把十进制 200 写成两位十六进制。

<details>
<summary>提示</summary>

1. 200 在 0–255 里，两位够写。先算 200 里有几个 16。
2. 200 ÷ 16 = 12，余 8。查上表：12 对应哪个符号？8 对应哪个符号？
3. 左边那个字符放 12 的符号，右边那个字符放 8 的符号。

</details>

<details>
<summary>答案</summary>

`c8`。200 = 12×16 + 8，12 是 `c`，8 是 `8`。正反各验一次：

```console
$ printf '%x\n' 200
c8

$ printf '%d\n' 0xc8
200
```

</details>

## 1.2 一个字节 = 两位十六进制

```console
$ printf 'A' | xxd
00000000: 41                                       A

$ printf '%x\n' 200
c8

$ printf '%d\n' 0x41
65
```

第一条命令：竖线 `|` 把左边输出交给右边当输入（管道，第 5 章 讲全）。`printf 'A'` 没写 `\n`，只输出一个字符 `A`；`xxd` 把它当一个字节，按三列显示：`00000000:` 是偏移，即它在串里的位置，第一个字节是 0（第 1 章）；`41` 是十六进制写法；右侧 `A` 是 `xxd` 按 ASCII 表画出来的字符（第 3 章 讲全，本章先接受这条），数值依据是第三条命令：`41` 就是 65。

**为什么一个字节正好两位，数数就能定。** 一个字节能表示 0 到 255 这 256 个数。一位十六进制 16 种取值；两位十六进制，左边 16 种、右边 16 种，16 × 16 = 256 种，刚好一对一盖住 0–255 这 256 个数。一位只有 16 种，装不下；三位 16 × 16 × 16 = 4096，多出来。所以字节固定两位。这三步只用乘法，你自己就能验。

`41` 就是这样一个字节：左边那个字符 `4` 乘 16，右边那个字符 `1` 乘 1，4×16 + 1 = 65，正是第三条命令的输出。第二条命令是 1.1 那道题的复核。

> **约定** 数字前的 `0x` 是「这是十六进制」的标记，`printf` 认它。手写时加 `0x`，免得与十进制混淆。

> **易错** 字节永远写两位：15 要写成 `0f`，不能写成 `f`。

```console
$ printf '%x\n' 15
f

$ printf '\x0f' | xxd -p
0f
```

同一个值 15：`printf '%x'` 是一个数的写法，能省就省；`xxd` 按字节写，一定两位。`\x0f` 是 `printf` 的另一种写法：`\x` 后面跟两位十六进制就是一个字节。少了那个 `0`，就看不出它是哪一格。

**速查：两个方向的换算**

| 想做什么 | 输入 | 本章实例 |
| --- | --- | --- |
| 十进制 → 十六进制 | `printf '%x\n' 十进制数` | `printf '%x\n' 200` 得 `c8` |
| 十六进制 → 十进制 | `printf '%d\n' 0x十六进制` | `printf '%d\n' 0x41` 得 `65` |

**U01.2-01** `printf 'A' | xxd` 的输出里有 `41`。这个字节的十进制值是多少？写出算法。

<details>
<summary>提示</summary>

1. `41` 是两位：左边那个字符是 `4`，右边那个字符是 `1`。
2. 左边那个字符代表 16 的个数（4×16），右边那个代表 1 的个数（1×1）。
3. 两项相加，再用 `printf '%d\n' 0x41` 对答案。

</details>

<details>
<summary>答案</summary>

65。算法：4×16 + 1 = 65。

```console
$ printf '%d\n' 0x41
65
```

同一个字节，`xxd` 写 `41`，十进制写 65。

</details>

## 1.3 为什么不用十进制

第 1 章 里的样本 `S-01.png` 先复制到你当前所在的文件夹（`.` 就是当前文件夹，`*` 会自己填上你的 Windows 用户名）：

```console
$ cp /mnt/c/Users/*/Downloads/S-01.png .

$ ls S-01.png
S-01.png
```

`cp` 报 `No such file or directory` 就是不在 Windows 的「下载」里：把 `Downloads` 换成你放它的文件夹名（桌面是 `Desktop`）再跑。

```console
$ printf '%d\n' 0xff
255

$ xxd -p -l 8 S-01.png
89504e470d0a1a0a
```

`-p` 是 plain（纯十六进制），只输出十六进制那列，省掉右侧的字符列；`-l` 是 length（长度），`-l 8` 只读前 8 个字节。文件名不对，就是这条报错：

```console
$ xxd -p -l 8 S-01.png
xxd: S-01.png: No such file or directory
```

这行说按当前文件夹找不到 `S-01.png`：先看 `ls S-01.png` 有没有回显。

那 16 个字符两个一组切开：`89 50 4e 47 0d 0a 1a 0a`，共 8 组，每组一个字节。这 8 个字节是 PNG 文件规定的开头；讲文件格式的章节会解释它们怎么来的，本章先接受。

为什么不用十进制：同一个字节，十进制下 0–9 占 1 个字符、10–99 占 2 个字符、100–255 占 3 个字符，长度不定；十六进制永远 2 个字符。所以「2 个字符 = 1 个字节」不看内容就成立，十进制做不到（`8`、`89`、`168` 都可能是一个字节）。文件头这类按字节对位的数据都用 hex。

> **实践** 拿到一串 hex，先两个字符一组切开：`414b` 是两个字节 `41` 与 `4b`。

**速查：本章会遇到的字节值**

十进制一列可用 `printf '%d\n' 0x…` 自己验；「是什么」一列来自 ASCII 表（第 3 章 讲全），本章只需认这几个。

| 十六进制 | 十进制 | 是什么 |
| --- | --- | --- |
| `00` | 0 | 空字节，值就是 0 |
| `0a` | 10 | 换行 |
| `20` | 32 | 空格 |
| `41` | 65 | 大写 `A` |
| `61` | 97 | 小写 `a` |
| `7f` | 127 | 删除符，终端上不显示 |
| `ff` | 255 | 一个字节能取的最大值 |

表里 `0a` 和 `61` 不是一回事：`0a` 是「换行」这个控制字符的字节值，不是字母 `a`；字母 `a` 的字节值是 `61`。

**U01.3-01** 一个字节的十六进制写法最大是多少？说明为什么不能更大。

<details>
<summary>提示</summary>

1. 一个字节是两位十六进制，每位最大是 `f`。
2. `ff` 的十进制是 15×16 + 15，先算出来。
3. 想更大就要进位成三位，跑 `printf '%x\n' 256` 看结果。

</details>

<details>
<summary>答案</summary>

`ff`。15×16 + 15 = 255，等于一个字节能取的最大值。再大就要三位，一个字节装不下：

```console
$ printf '%x\n' 255
ff

$ printf '%x\n' 256
100
```

</details>

## 动手

把 0、15、16、255 各跑一次，补成两位写法。

```console
$ printf '%x\n' 0
0

$ printf '%x\n' 15
f

$ printf '%x\n' 16
10

$ printf '%x\n' 255
ff
```

四个结果补零后是 `00`、`0f`、`10`、`ff`；再反验 `0f`：

```console
$ printf '%d\n' 0x0f
15
```

## 小结

两位十六进制 16 × 16 = 256 种，正好盖住一个字节的 0–255，所以字节永远写两位。十进制写同一个字节可能占 1、2、3 个字符，所以原始数据用 hex。给定 0 到 255 的数，你能手写两位 hex 并用 `printf` 双向核对。

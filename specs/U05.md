# U05 · Python 最小可用：五件事够用

出口能力：写一个 20 行以内的脚本，读文本文件、按字段筛选、输出统计结果。
复用点：U21 U22 U30 U31 U41
样本动作：无独立样本动作，所有例子都跑在 `u01-access.log` 上（与 U04 同源，便于对照两种做法）
新增概念：script, variable, string, list, dict, function

## 明确不教

- 面向对象、类、继承——本课用不到
- 异常处理（`try/except`）——只在 U06 读二进制失败时给最小用法，不系统讲
- 模块与包、虚拟环境、pip——U06 之后需要第三方库时再讲
- 生成器、装饰器、类型注解、异步
- `lambda` 只在动手题的提示里出现一次，解释为「匿名函数」，不展开

## 已知遗留

1. 没有讲 `try/except`，但 2.5 节说了「文件不存在会报 FileNotFoundError」——读者可能想捕获它。留到 U06 读二进制时再补，因为那时才真的必须捕获。
2. 2.3 的推导式只给了两种形态（映射与筛选），没给「同时映射+筛选」。等 U41 过滤抓包时补。
3. 本章没有独立的贯穿样本动作，全部例子跑在 U04 的日志上。这是有意的：让读者看到同一份数据用管道和用脚本两种解法，但代价是 U05 在样本集上没有自己的进展。

## 明确不教

- `awk` 的编程语法（只用 `$N` 与 `$N==x` 两种形式），完整用法放 U41 过滤抓包时再讲
- `find`、`xargs`、`tar`——后两个在 U12 解压缩包时才需要
- 正则表达式——U11 解 URL 编码时顺带讲，不单独成节
- shell 脚本（变量、`if`、函数）——本课不要求写脚本，`for` 循环只在下载样本时用一次

## 实测记录

环境：WSL Ubuntu-24.04，`coreutils 9.4`，`python3 3.12`。
样本：`static/samples/u01-access.log`，30 行，由 `scripts/build-corpus.py` 确定性生成（各 IP / 路径 / 状态码条数写死）。

| 命令 | 实跑输出 | 与正文一致 |
| --- | --- | --- |
| `wc -l < u01-access.log` | `30` | 是 |
| `awk '{print $2}' … \| uniq -c \| wc -l` | `25` | 是 |
| `awk '{print $2}' … \| sort \| uniq -c \| wc -l` | `5` | 是 |
| `… \| sort -rn \| head -3` | `10 203.0.113.7` / `8 198.51.100.23` / `6 192.0.2.88` | 是 |
| `cut -d' ' -f5 … \| sort \| uniq -c \| sort -rn` | `23 200` / `5 404` / `2 302` | 是 |
| `grep -c '/login ' …` | `6` | 是 |
| `awk '$5==404' … \| wc -l` | `5` | 是 |
| `head -1 \| sed 's/T/ /'` | `2026-11-10 08:00:00Z 198.51.100.23 …` | 是 |
| `strings -a S-06.pcap \| grep -o 'GET [^ ]*' \| cut -d' ' -f2` | `/files/%E4%BD%A0%E5%A5%BD.txt` | 是 |
| `strings -a S-06.pcap` | 9 行，含 `Host: ctf.example`、`Cookie: sid=UzA2LWh0dHAtYjY0LW9y` | 是 |

## 已知遗留

1. `ls -l` 的示例输出是本机（WSL）的，读者环境不同则大小/时间不同，正文已说明「只看列的含义」。
2. 1.2 与 1.4 未设节题（由 1.5 与自检覆盖），与 v4「每节 1–2 题」有偏差，理由：这两节是纯机制，题放在应用处更有效。
3. `cut` 不合并连续分隔符这条只有文字说明，没有配可跑的反例。下一步可在 1.4 补一个双空格的失败示例。

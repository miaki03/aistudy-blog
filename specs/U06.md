# U06 · Python 与字节：str 和 bytes 是两种东西

出口能力：用 `open(p,"rb")` 读二进制文件，按偏移切出任意一段并对它做处理。
复用点：U12 U21 U22 U31 U41 U61
样本动作：S-04 定位 gzip 偏移并解压（节 3.4 + 动手 U06.6-01）；S-01 取 IHDR 宽高（自检 U06.5-02）
新增概念：bytes-type, encode-decode, endianness

## 明确不教

- `bytearray`（可变字节）——本课用不到，`bytes` 拼接足够
- `struct` 模块——读 PNG 时用 `int.from_bytes` 更直白；等 U41 解析 pcap 结构再上 `struct`
- 编码家族（GBK / Latin-1 / UTF-16）——只在速查表出现一行，不展开
- 大文件分块读——样本都在 MB 以下

## 实测记录

环境：WSL Ubuntu-24.04，`python3 3.12.3`。

| 命令 | 实跑输出 | 与正文一致 |
| --- | --- | --- |
| `"abc".encode()` | `b'abc'` | 是 |
| `"你好".encode()` | `b'\xe4\xbd\xa0\xe5\xa5\xbd'` | 是 |
| `len("你好".encode())` | `6` | 是 |
| `'abc' + b'def'` | `TypeError: can only concatenate str (not "bytes") to str` | 是 |
| `b'\xff'.decode()` | `UnicodeDecodeError: 'utf-8' codec can't decode byte 0xff in position 0: invalid start byte` | 是 |
| `b'\xe4\xbd'.decode(...,'replace')` 长度 | `1` | 是 |
| `b'A'[0]` / `b'A'==65` / `b'abc'=='abc'` | `65` / `False` / `False` | 是 |
| `(64).to_bytes(4,'big').hex()` | `00000040` | 是 |
| S-04 `f.read(8).hex()` | `9959f1bfa35ca775` | 是 |
| S-04 `find` 偏移 | `32` | 是 |
| S-04 从 32 解压 | `S04 gzip payload: offset-found` | 是 |
| S-01 `int.from_bytes(d[16:20],'big')` | `64` | 是 |

## 已知遗留

1. `errors='ignore'` 只给了「危险」的警告，没有配一个「长度凭空变化」的实测例子。可以补：`b'\xe4\xbd'.decode(errors='ignore')` 长度为 0。
2. 字节序只讲了 big/little 的判据（网络与图片 big，ELF/PE little），没给「先试一遍看哪个数合理」的实操演示。
3. 3.4 只演示了 `gzip.decompress`，没讲 `zlib` 与 `gzip` 的区别。留到 U12。

## 踩到的坑（值得记）

**`verify` 命令走的是 `/bin/sh`（dash），不是 bash。** 第一版 U12.1-01 的 verify 写成
`printf '\x89PNG\r\n\x1a\n' > /tmp/x && file -b /tmp/x`，在 bash 里正确、在 dash 里 `\x` 不被解释，
结果 `file` 报 `ASCII text, with CRLF, LF line terminators` 而不是 `data`——`check.py` 当场抓出来。

规则：**凡是要生成二进制内容的 verify，一律用 `python3 -c "open(...,'wb').write(b'...')"`**，
不要依赖 shell 的 `printf` 转义。

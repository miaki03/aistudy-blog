## 1. 这本书是什么

一套面向**单人自学**的 ARG / CTF / Puzzle Hunt 教材，发布在静态博客上，按章阅读。

**读者画像**（写的时候一直想着这个人）：

- 会用电脑日常操作，但**没有受过系统的计算机训练**（不知道位、字节、编码是怎么回事）；
- 中文母语，**英文弱**：能读懂简单句子，读长句和技术文档会放弃；
- 要一个人学，**没有人可以问**；
- **不愿意跳出去搜索**——凡是要他开新标签页查的东西，都可能让他停下；
- 学这门课的目标是能独立解 CTF 的 misc 题、Puzzle Hunt 单题、追 ARG 线索。

**只有这一条。** 不要写成三条目标。不要顺手教十六进制原理、ASCII、UTF-8——它们各自有章。

## 5. 节表与实测跑通物（输出都是我跑过的真实结果，照抄）

### 0.1 在终端里跑第一条命令

```console
$ pwd
/mnt/f/vibecoding/learning-path-site

$ ls
README.md  content  docs  hugo.toml  kb  scripts  static
```

- 机制要讲清：终端是「你打字、它执行、它回话」的窗口；一条命令 = 名字 + 参数；`pwd` 与 `ls` 各自回答什么问题。
- 速查：`pwd` / `ls` / `ls -l` / `cd` 四条，各一句。
- **必须给**：Windows / macOS / Linux 三平台怎么打开终端（读者多半在 Windows）。

### 0.2 用 `xxd` 看见字节

```console
$ xxd -l 16 static/samples/S-01.png
00000000: 8950 4e47 0d0a 1a0a 0000 000d 4948 4452  .PNG........IHDR
```

- 机制要讲清三列：**偏移**（从 0 数，写成十六进制）、**每字节两个字符**、**可打印字符**（不可打印显示 `.`）。
- 只讲「这两个字符代表一个字节」这一层，**不要展开十六进制怎么换算**（U01 讲）。可以写一句「为什么是十六进制，下一章讲」。
- 速查：`xxd -l N` / `xxd -s 偏移` / `xxd -p` 三条。

### 0.3 文件就是一串字节

```console
$ file static/samples/S-01.png
static/samples/S-01.png: PNG image data, 64 x 64, 8-bit/color RGB, non-interlaced
```

- 机制要讲清：`file` 是**读开头几个字节去猜**，不是读扩展名；改名成 `.txt` 结论不变。
- 一句「猜测会和事实不同」的预告即可，不要展开伪装手法（U12 讲）。

## 6. 风格规范

**必须读 `docs/02-style-guide.md` 全文并遵守。** 要点复述：

- 每条命令给**完整会话**（`$` + 命令 + 真实输出），不许省略成 `...`；
- 术语首次出现当场定义，**不许要求读者自己搜**；
- **禁止比喻**（「就像……」「好比……」一律不要），讲机制；
- 三种 inline 标记：`> **易错**` / `> **约定**` / `> **实践**`；
- 练习答案用 `<details><summary>提示</summary>` 与 `<details><summary>答案</summary>` 两段折叠。

## 7. 概念边界

本章**允许新增**的概念（只能这三个）：

| id | 中文 | English |
| --- | --- | --- |
| `byte` | 字节 | byte |
| `offset` | 偏移 | offset |
| `printable` | 可打印字符 | printable character |

**不要**新增 `hex`、`ascii`、`utf8`、`text-vs-binary`——它们分别是 U01/U02/U03 的概念。

## 9. 题目（题面由你写，考点与机验由我定）

| 编号 | 考点 | 我会用的 verify |
| --- | --- | --- |
| U00.1-01 | `wc -c` 给字节数，且 `<` 让输出只有数字 | `wc -c < static/samples/u01-access.log` → `1681` |

每题都要写**提示**（1–3 条递进）与**答案**（含可复跑命令）。

## 10. 篇幅参考

**1200–2000 字**（含练习站指引）。这是预警不是门槛：如果某段删了读者就做不出来，保留并说明。反过来超过上限要先自问「这段能不能挪到 U01」。

## 11. 练习站指引（本章必须包含）

终端是**手熟型**知识，不要在本章手把手教完。请在 0.1 节末尾加一小段：

- 指向 **OverTheWire: Bandit**（免费、SSH 直连、免注册）；
- 说清**打哪几关**：0–5 关；
- 说清**为什么是这几关**：它们只需要 `ls`/`cat`/`cd`/`file`，正好覆盖本章；
- 补练习站缺的东西：**它只给线索不给解释**，所以把这几关会用到的命令一句话解释清楚；以及**报错怎么读**（`No such file or directory` 意味着路径写错，不是权限问题）。

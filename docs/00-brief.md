# 项目说明（北极星）

## 一句话

给一个计算机专业大一学生，做一套**能独立学完、不用跳出去搜**的 ARG / CTF / Puzzle Hunt 入门到中阶课程。

## 读者画像

| 维度 | 事实 |
| --- | --- |
| 身份 | 计算机科学与技术大一，中日合作项目 |
| 编程 | 有命令行基础；Python 不熟；正在学 C |
| 解谜 | 仅「玩过解谜游戏」的水平，无 Puzzle Hunt / CTF 经验 |
| 英文 | 较弱，希望中文为主 + 英文资源有导读 |
| 时间 | 每周 5–10 小时，课业与日语课会占时间 |
| 基础 | **有计算机基础**，能接受原理讲解，反感比喻和类比 |
| 目标 | 单人可玩：CTF 独立解题、Puzzle Hunt 单人完成、ARG 能拆解与自建 |

## 硬约束

1. **保姆级**：阅读过程中不需要跳出页面去搜索。概念当场解释，命令给全，输出给全。
2. **原理优先**：讲机制、讲推导；禁止用比喻代替解释（比喻在懂计算机的人身上常常起反作用）。
3. **题目必须可验证**：要么能机器跑出答案，要么有可核对的人工证据。
4. **不转载题面**：只链接原题 + 自写解法，规避版权与链接失效。
5. **单人可完成**：练习阶梯只保留 `[S]` 项。
6. **免费**：不依赖付费平台。

## 成功标准

- 每个技能页读者能「读完后不查资料做出 3 道题」；
- 每个项目页有明确交付物与评分标准；
- 全站无死链、无「自行搜索」式指引；
- `scripts/check-kb.py` 通过。

## 非目标

- 不做 pwn / kernel / 高级逆向 / 密码学深水区；
- 不做视频、不做交互式判题（暂定）；
- 不追求日更，追求单页质量。
